01 / 故事长卷

沿着他的来路

点开节点，读懂转折的前因后果。

先分清三个“东临”

按先后阅读，或切到重创、修为、爱情和亲友线。

悟道发生在哪里：逐条查阅地点与成果

每一步，如何走上去

按大境界逐级展开，补充有明确场景的小阶段。并列记录强敌与结果，不把同期交战当作突破的直接原因。

并行修行：古神本尊 → 道古之身

古神之地取得涂司的记忆传承 → 化神前后，本尊散去修士修为、专修古神 → 朱雀星后期三星古神 → 星空历练至五星 → 云海渡一损两劫，经历伪六星与碎星代价 → 界外烨寞传承，走向七星道古体 → 洞府后期八星及多系星点继续成长 → 仙罡仙古融合、古祖魂血与分神劫。

这一支以古神／古魔／古妖星点及劫难计，不与修士境界一对一换算。拓森是传承与争夺中的长期强敌；古道则是仙古融合之后面对的巅峰对手。星点受损、恢复与不同体系合计容易混淆，未逐章核定的每一颗星不另造突破事件。

02 / 境界图谱

境界是阶梯，悟道是转折

这里列的是世界观的境界体系，不表示王林逐级、等速通关。他的本尊、分身与古神之路并行，不能把古神星数机械换算成某一修真境界。

03 / 人物关系图

故人在四方，因果有来处

点选人物，辨清身份与关系变化；沿事件回到故事。

柳眉是木冰眉的分身；王平是王林与柳眉之子；周茹是被养育的孩子。

东梅是李倩梅转世；宋致曾被置入婉儿残魂，始终是独立的人。三者不能当作李慕婉的改名。

06 / 阅读说明

以小说为轴，以动画为影

这是围绕王林整理的全书主线导读，不是逐章复述。节点标题与解读为重新归纳；“转折”说明因果，“人物线”说明关系如何变化。动画只作人物视觉参考，不用于替代小说情节。

原著存在闭关、梦道、转世与时间逆转等不同计时方式。公开编年资料的年龄数字也有差异，因此本页采用相对先后，不给未经逐章核对的事件强配年龄或章节号。大事件已拆开记录。没有逐章核定的过渡时点会显式注明；本页不把借魂铠、毁分身或复原外貌当作真实境界晋级。
