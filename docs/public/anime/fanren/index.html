06 / 阅读说明

以原著为轴，循线重读

这是围绕韩立整理的原著主线导读，含本传结局剧透。十一卷导航沿用小说分卷顺序；故事节点、标题与说明由本页重新归纳，覆盖重大转折与代表性小阶段，适合回顾和定位。

资料查阅包含正版入口、目录与读者整理。公开年历的年龄、个别名称和分章有差异，因此本页采用相对先后，没有给所有事件强配精确年岁或章号。节点末尾的资料链接是进一步核对的入口；不表示已经完成逐章校勘。

修为、重修恢复、法宝增强与外部助力分别标注。炼虚中期在广寒界连续灌体中单列为过程，合体突破放在回归后的闭关。与圣祖化身交战不等同于斩杀本体；主要胜战保留环境、援手和对手状态。

人物战力榜按篇章出现状态和本传代表层次分档，档内并列。分档属于读者归纳；缺乏同条件交战依据的仙级、真灵、残魂与分魂另外说明。《仙界篇》的后续境界未纳入本传榜。
