01 / 故事长卷

一路向前，也一路回望

读故事，也看每次突破的条件与代价。

读这条时间轴，先分清三件事

境界与借来的战力帝关的“他化自在”有特殊真血相助；安澜之战的力量另列说明。

仙气、骨与轮回印它们属于道基、宝术与复苏的线索；修为阶梯按实际突破记录。

本作与后续作品主线止于荒天帝平乱、独断万古与上苍之上的入口。

每一步，如何走上去

把地点、突破条件、对手和结果放在一起看。道基重塑、借力与复苏单列说明。

境界之外：四条贯穿一生的力量线索
此处暂无线索

试试“柳神”“鲲鹏巢”或“安澜”，也可以回到完整故事。

此处排列石昊实际走过的大境界。仙气是道基，“以身为种”是修行方法；至尊骨的变化、轮回印的归一与阶段性战力分别说明。小阶段未逐章核定的部分采用阶段概括。

卷外 / 跨越岁月的线索《遮天》与《圣墟》

叶倾仙、曹雨生及未来时空的来客连接了更大的故事。后续作品展开的身份、复活与更高层级修行，留在各自作品中阅读。

06 / 阅读说明

以小说为轴，循线重读

这是围绕石昊整理的《完美世界》全书主线导读，包含结局剧透。十段旅程是本页的阅读分段，故事标题与解读为重新归纳，适合回顾重大事件、修为变化和人物关系。

采用相对先后，节点距离不表示真实年数。早期顺序、九世成仙与终局阶段参考原著目录、许可译本及人物资料交叉核对；公开预览和目录不能替代完整原文。尚未完成逐章校勘的年龄、小境界时点和轮回印逐道来源不强配数字。

帝关战安澜时的借力与永久修为分开；尊者境的道基重塑与首次突破分开；冲击仙王时遭三王狙杀、葬土复苏和真正成王分开。三准仙帝、灭世老人、尸骸仙帝分别记述，后续作品中的诡异始祖与祭道等阶段另属其他故事。

卷首图由内置 imagegen 生成，表现群山、柳树与远行的氛围。战力榜另配三时期象征长卷和六人物画像。所有配图都是想象插画，角色外观与环境不作为原著场景或动画形象的证据；同一人物画像用于识别身份，不表示各阶段外观相同。程序、图像和字体均可本地使用；正文资料链接需要联网。
