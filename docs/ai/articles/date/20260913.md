# 226 本绘本，都是晚上电脑不休息跑出来的

![亲子共读绘本封面](/images/articles/20260913/cover.png)

孩子喜欢听绘本故事。

这件事本身很普通，但它驱动了我做一个不太普通的事情：用目前最好的生图模型 GPT-image-2，一本一本地生成 AI 儿童绘本，直到现在绘本馆里已经有 226 本。

## 怎么做到 226 本的

Codex 每天有使用额度，快要重置的时候我就赶紧用一用，把生成任务排上。晚上睡觉也不让电脑休息，让它安安静静地跑绘本插图生成任务。每本绘本 8 到 20 页插图，每页都要单独调用模型生成，一本跑完通常需要好几分钟。就这样日积月累，绘本馆慢慢从最初的几十本，涨到了现在的 226 本。

目前一共有 6 个系列：

| 系列 | 数量 | 简介 |
|------|------|------|
| 成语故事 | 50 本 | 守株待兔、画蛇添足、愚公移山……每个成语一本完整绘本 |
| 西游记 | 70 本 | 从石猴出世到取经归来，按回目改编的儿童版 |
| 好奇为什么 | 30 本 | 天空为什么是蓝色的、恐龙为什么会灭绝、萤火虫为什么会发光 |
| 唐诗入画 | 44 本 | 静夜思、春晓、咏鹅……每首唐诗变成一本图文绘本 |
| 三字经·亲子成长 | 6 本 | 用绘本讲三字经里的道理 |
| 城市汽车小队 | 26 本 | 消防车、救护车、挖掘机……各种车辆的故事 |

不知道大家有没有去听一听。我家孩子特别喜欢城市汽车小队系列，于是我又围绕这个主题多生成了好几本，从消防车、救护车一直做到挖掘机、搅拌车、压路机。

每本绘本都支持中英双语阅读、语音朗读和视频生成，打开就能讲给孩子听。

## 微信小程序：方便但也有坑

为了让大家更方便体验，我尝试做了微信小程序。

扫描下面的二维码就能打开：

![StoryBloom 微信小程序](/images/articles/20260913/miniprogram-qr.jpg)

不过老实说，小程序开发并不顺利。迫于个人注册的小程序无法通过有声读物类目的审核，还要付费做微信认证，所以目前小程序用是能用的，但没法分享到微信群和朋友圈，也无法再更新优化了。有声读物类目属于特殊行业资质，个人开发者基本走不通。

如果只是自己打开体验一下，扫码还是可以正常使用的。

## 绘本馆变成了 Web App

另一个改进是把绘本馆的网页做了优化，从普通的 H5 页面升级成了 Web App。添加到手机主屏幕之后，像打开一个独立应用一样使用，没有浏览器地址栏的干扰，体验更接近原生 App。

具体操作：

**iPhone / iPad**：用 Safari 打开绘本馆，点击底部"分享"按钮，选择"添加到主屏幕"。如果看到"作为 Web App 打开"的提示，保持开启即可。

**Android**：用 Chrome 打开绘本馆，点击浏览器菜单里的"安装应用"或"添加到主屏幕"。如果是在微信里打开的链接，需要先点击右上角选择在系统浏览器中打开。

绘本馆地址：**https://storybloom.valleylmh.vip/library**

轻点图标，就像打开 App 一样开始亲子共读。
