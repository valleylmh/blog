# 老婆夸我网站做得好，因为儿子的幼儿园证件照真挺像

![OutfitLens 公众号封面](/images/articles/20260712/cover.png)

`网站上线了一段时间，访问量一直不多。没想到，它第一次让我觉得“做得还不错”，不是因为数据涨了，而是今年儿子的幼儿园证件照没再去摄影工作室，直接用一张生活照生成了。老婆看完说：网站做得挺好，照片也很像。`

网站上线已经有一段时间了。

我偶尔会打开微软 Clarity 看看访问情况，但数据一直很安静。没有突然增长的访问量，也没有很多陌生用户涌进来体验。现在为数不多的用户，大多还是看了我发的公众号文章，才点进去试一试。

做独立产品，大概经常会经历这样的阶段：功能一点点做出来了，网站也真的上线了，可它暂时还只是互联网角落里一个很小的存在。

前段时间，又需要准备孩子的幼儿园证件照。

往年遇到这种事，我们通常会找时间带儿子去摄影工作室。要选时间、出门、换衣服，再让孩子坐好看镜头。小朋友状态好的时候还算顺利，状态不好时，一张看起来简单的证件照也要折腾一阵。

今年我突然想到：我做的 OutfitLens 本来就有证件照功能，为什么不直接拿儿子的生活照试一下？

我找了一张正面比较清楚的照片上传，选择证件照模式，再选好背景、尺寸和幼儿园证件照的服装，点击生成。原来站在小区里的普通生活照，很快变成了一张白底、正面、衣着整齐的证件照。

![OutfitLens 公众号封面](/images/articles/20260712/0.png)

真正让我高兴的，不是背景换干净了，也不是衣服看起来更正式，而是生成出来的孩子还是他自己。

脸型、五官和神态都保留得比较自然，没有变成一个只有几分相似的“AI 小孩”。老婆看完后也夸我，说这个网站做得挺好，儿子的证件照非常好，也非常像。

这句话对我来说，比后台多几个访问量更具体。

做这个网站时，我花了很多时间调整上传、选择、生成和下载这些环节，也反复比较不同模型对人物特征的保留效果。平时面对的都是页面、代码、任务状态和数据，很容易把“产品”理解成一堆功能是否正常运行。

但这次我忽然觉得，一个产品真正有意义的时刻，可能没有那么宏大。

它只是让我们今年不用专门跑一趟摄影工作室；让一张随手拍的生活照，变成了幼儿园需要的证件照；也让我做了很久的东西，第一次被家人用一种非常直接的方式认可。

当然，AI 生成的证件照并不适合不加判断地用于所有正式证件。不同学校、考试和机构对尺寸、背景、清晰度都有自己的要求，提交前还是需要认真核对。但像幼儿园资料照、班级信息照，以及一些要求相对简单的电子照片，它确实可以省下不少时间。

OutfitLens 现在除了证件照，也可以用一张人像照片生成换装效果、职业照、毕业照、未来形象和其他个人照片。我还在继续完善它，访问量也依然不算多。

不过这张儿子的证件照让我觉得，先别急着被流量打击。

如果一个产品已经能帮一个真实的人解决一件真实的小事，它就不是一个只停留在电脑里的半成品。接下来要做的，是让更多恰好有需要的人知道它。
