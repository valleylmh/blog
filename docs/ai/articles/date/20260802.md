# StoryBloom 开源了：一个给孩子讲故事的 AI 绘本生成器

![StoryBloom 开源发布封面](/images/articles/20260802/cover.webp)

做 StoryBloom 的起点很简单：想给孩子讲一个属于他自己的故事。

市面上的绘本很好，但它们属于出版社和插画师。我只是想，如果孩子今天说了一句"月亮会不会也害怕黑"，我能不能很快把这句话变成一本有插图的小绘本，当晚就讲给他听。

StoryBloom 就是这样开始的。从一句话生成 8 页中英双语故事，配上统一风格的插图，可以朗读、保存、导出长图、生成竖屏视频，也可以通过分享链接发给家人。做了几个月，功能一轮轮加上去，极简模式、完整模式、主角管理、每日灵感、个性化偏好、绘本视频、社交分享，它慢慢变成了一个相对完整的产品。

现在，我把它开源了。

## 为什么开源
![StoryBloom 开源](/images/articles/20260802/opensource.png)
一个人可以把产品做出来，但很难同时兼顾不同模型的适配、部署环境的差异、插图风格的扩展、儿童内容的安全审查，以及真实家庭五花八门的使用习惯。

我希望有需要的人可以直接部署自己的版本，也希望有兴趣的开发者能一起改进它。不管是补充新的画风、优化角色一致性、接入本地模型，还是把它用在亲子阅读、幼儿园活动或公益场景里，我都很期待看到。

开源地址：**https://github.com/valleylmh/storybloom**

如果对你有用，请给个 Star。

## 绘本馆：不只是生成，还有可以直接看的经典故事

![StoryBloom 绘本馆](/images/articles/20260802/library.png)

除了 AI 绘本生成，我还给 StoryBloom 加了一个绘本馆。

这个想法来自一个很朴素的需求：不是每次打开都想生成新故事，有时候只是想快速找一个经典故事，配上插图讲给孩子听。

目前绘本馆里包含三个系列：

- **成语故事**，20 个。守株待兔、画蛇添足、刻舟求剑这些，每个成语都用完整的 8 页绘本重新讲了一遍，配上插图和中英双语文本。
- **西游记**，40 回。从石猴出世到取经归来，按原著回目顺序改编成适合孩子阅读的短篇绘本。
- **好奇为什么**，10 个。天空为什么是蓝色的、恐龙为什么会灭绝、月亮为什么会变形状——针对孩子常问的"为什么"，用故事的方式讲科学常识。

这些绘本都可以直接在线阅读、朗读，也支持生成长图和视频。它们不需要登录，不需要消耗积分，打开就能用。

绘本馆地址：**https://storybloom.valleylmh.vip/library**

## 体验和参与

如果你正好在找一个给孩子讲故事的小工具，可以打开线上版试试：

**https://storybloom.valleylmh.vip**

输入一句话，选一个主角，系统会生成完整的 8 页中英双语绘本。极简模式下甚至不需要注册，写下想法就能开始。

如果你是开发者，也欢迎看看源码、提 Issue 或者 PR。技术栈是 Next.js + TypeScript，插图模型支持多 Provider 配置和自动回退，语音朗读走的是 Gemini TTS 加 Edge TTS 兜底。
![StoryBloom 体验](/images/articles/20260802/share.png)

仓库里有 README 和 ROADMAP，写了目前的能力边界和后续计划。
