# 额度快过期了，干脆做几个小游戏给儿子玩

![cover](/images/articles/20261017/cover.png)

五月份开始订阅 ChatGPT 会员，续费到现在快半年了。这半年陆陆续续用 AI coding 做了三个 Web 产品，部署在 Vercel 和 Cloudflare 上，从想法到上线的链路跑通了好几遍。

但到了九月底，突然没思绪了。

不知道做什么。身边能挖掘的需求好像都挖过一轮了，每每打开电脑发呆了好几次。

与此同时，GPT 的额度机制一直在制造焦虑——动不动就重置，用不完就浪费了。这种微妙的倒逼感反而推着我去想：既然额度在那里，总得做点什么吧。

## 那就做小游戏

想法出现得很随意。不是规划出来的，更像是闲着没事，顺手试了试——"要不做个台球？"

于是从中式八球开始，一发不可收拾。

八球桌球做完之后，觉得手感不错，又做了闪电出租车赛车——3D 街机风格，六辆车同场竞速，还有氮气加速和动态天气。接着是一系列益智小游戏：小车挪挪挪、果园消消乐、汽车翻翻乐、数字华容道、破译密码、熄灯小管家、小小搬运工、接通水管、小小建筑师。

国庆期间前前后后，做了 11 款。

![游戏合集](/images/articles/20261017/game-arcade.png)

一方面是本着"不浪费额度"的原则，每次快重置了就赶紧排上生成任务；另一方面，每做完一个游戏，看到它真的能跑起来、能玩，那种成就感是很实在的。不像写业务代码，小游戏的反馈回路特别短——改一行代码，刷新页面，立刻看到效果。

## 没想到的事

做这些游戏的时候，我脑子里其实有个模糊的想法：给我家五岁的儿子玩。

小车挪挪挪可以练逻辑推理，汽车翻翻乐可以练记忆力，小小建筑师可以培养空间想象力，数字华容道可以锻炼手指灵活度和规划能力。每个游戏我都刻意做了"无倒计时"的模式，不给孩子压力，让他慢慢想、慢慢试。

然后我把游戏打开给他看。

他挨个试了试，在小车挪挪挪上认真想了一会儿，果园消消乐玩了两局，翻翻乐翻了几轮——

最后一头扎进了闪电出租车，再也不肯出来了。

方向盘左右摇，氮气一按，嘴里"嗖嗖嗖"地配音，完全沉浸。我精心设计的那些益智游戏，在赛车面前毫无竞争力。

回过头想想，这大概是他人生中第一次接触电子游戏。而造成这件事的人，是他爸爸。😅

## 额度焦虑的另一面

说实话，GPT 的额度机制确实烦人。但换个角度看，正是这种"用不完就没了"的压力，把我从"不知道做什么"的状态里拽了出来。

如果额度是无限的，我可能会继续发呆，继续等一个"完美的需求"出现。但因为额度有期限，我反而放下了"一定要做有用的东西"的包袱，允许自己做一些纯粹好玩的事情。

十一款小游戏，没有商业计划，没有用户增长目标，甚至没有正经的产品定位。但它们每一个都能打开就玩，手机电脑都行，不用下载不用注册。

这可能就是个人开发者最舒服的状态：不为谁做，但做出来的东西，至少自己的孩子会玩。
